# 笑声片段音频播放可视化设计

日期：2026-07-28

状态：已确认

适用分支：`fj_ver`

## 1. 背景

回顾详情页中的“笑声片段”已有音频点击播放能力，但当前播放行始终显示静态播放图标，没有播放、暂停、进度或完成状态。播放异常也会被静默忽略，用户无法判断点击是否生效。

真机检查确认现有笑声文件路径有效，文件为 16-bit、16 kHz、单声道 PCM WAV，Android `MediaPlayer` 可以正常启动播放。本设计只解决播放显示与控制；录音电平过低问题另行处理。

## 2. 目标

- 在笑声片段卡片内提供紧凑的播放与暂停控制。
- 使用音频文件本身计算真实波形，而不是装饰性动画。
- 波形和时间与实际播放进度同步。
- 对历史 moment 直接生效，不修改已有 event JSON 数据结构。
- 保持短期和长期回顾现有内容、布局层级和媒体浏览功能不变。

## 3. 不在本次范围内

- 不调整采集端麦克风增益或录音电平。
- 不对音频做响度归一化、放大或重新编码。
- 不加入拖动定位、倍速播放、后台播放或通知栏播放控制。
- 不修改视频和照片的查看逻辑。

## 4. 交互设计

每条音频使用紧凑胶囊式播放行：

- 左侧为圆形播放/暂停按钮。
- 中间为真实波形，已播放部分使用 App 现有珊瑚色，未播放部分使用低强调灰粉色。
- 波形下方为细进度线，与波形进度同步。
- 右侧显示当前播放时间；默认和复位状态为 `00:00`。

状态行为：

1. 默认状态显示播放图标、完整灰色波形和 `00:00`。
2. 点击播放后切换为暂停图标，时间开始推进，已播放波形逐段变色。
3. 再次点击同一行后暂停，图标切回播放，时间和波形停留在当前位置。
4. 暂停后再次点击，从当前位置继续播放。
5. 点击另一条音频时，当前音频停止并复位，新音频开始播放。
6. 播放自然结束后，当前行恢复默认状态。
7. 页面离开或销毁时停止播放器并复位界面。

## 5. 波形生成

新增一个与 Android UI 无关的 WAV 波形计算组件：

- 输入为本地 WAV 文件路径和目标柱数量。
- 校验 RIFF/WAVE、PCM、16-bit 等必要格式信息。
- 从 `data` 区读取 PCM 采样。
- 按目标柱数量将采样分桶。
- 每个桶计算归一化峰值或 RMS 振幅，输出 `0.0–1.0` 的数组。
- 对静音或极小音频保留最小可见高度，但不伪造内容起伏。

波形计算在后台线程执行。结果以“文件路径 + 文件长度 + 最后修改时间”为缓存键存入内存，避免卡片重绘或暂停恢复时重复扫描文件。

如果文件不存在、格式不支持或读取失败：

- 播放行保持可识别的不可用状态。
- 不启动 `MediaPlayer`。
- 通过 Toast 和开发日志说明失败原因。
- 不影响页面中的其他笑声片段、照片或视频。

## 6. 播放状态管理

`EventDetailActivity` 继续持有单个 `MediaPlayer`，同时记录：

- 当前播放文件路径。
- 当前绑定的音频行视图。
- 当前播放或暂停状态。
- 进度刷新任务。

播放进度按短周期刷新，但只更新当前活动音频行。切换音频、播放完成、页面停止或播放错误时，必须取消旧进度任务并释放播放器，避免多个刷新任务或播放器并存。

播放器需要注册准备完成、播放完成和错误回调。异常不能再被静默吞掉，必须写入 `AtlasDevLogger` 并向用户显示简短提示。

## 7. 组件边界

- `AtlasWavWaveformExtractor`：解析 PCM WAV 并生成归一化振幅数组，不依赖 Android UI，可用 JVM 单元测试验证。
- 音频行视图绑定逻辑：负责播放/暂停图标、波形、进度和时间显示。
- `EventDetailActivity`：协调播放器生命周期、音频切换和错误处理。
- 自定义波形 View：只负责按照振幅数组和当前进度绘制波形，不读取文件、不控制播放器。

## 8. 测试与验证

自动测试：

- 有效 16-bit 单声道 PCM WAV 能生成指定数量的振幅柱。
- 不同振幅输入产生不同波形高度。
- 静音音频输出稳定且不会除零。
- 无效 WAV、缺失数据块和空文件返回明确失败。
- 播放状态转换覆盖播放、暂停、继续、切换和完成复位。

构建验证：

- 运行全部 JVM 单元测试。
- 构建 debug APK。
- 执行 `git diff --check`。

真机验证：

- 在现有 `00_event_1` 的四条笑声片段上确认真实波形不同。
- 点击后图标切换为暂停，时间和波形随播放推进。
- 暂停和继续保持当前位置。
- 切换片段时上一条复位。
- 自然播放结束后复位。
- 返回回顾页后没有残留音频。
- 视频和照片仍可正常查看。

## 9. 验收标准

- 用户点击笑声片段后能立即看到明确的播放状态。
- 波形来自实际 WAV 内容，并随真实播放位置推进。
- 同一时间最多播放一条音频。
- 播放失败不再表现为“没有动静”。
- 既有 moment 无需迁移即可显示波形。
- 本次修改不改变音频原始音量。
